# Regulamento Geral da Formula Student FEUP - editable LaTeX

This version uses normal LaTeX structure: `\chapter`, `\section`, `\subsection`, standard lists, and an automatic `\tableofcontents`.

Global formatting lives in `styles/document.tex`. Chapter content lives in `chapters/`.

Compile with:

```bash
make
```

The document must be compiled at least twice so the table of contents resolves.
